# SynoTheo

> *Synopsis Theologica* — plataforma para criação e organização de esboços bíblicos, com uma experiência visual em 3D.

## Sobre

O SynoTheo permite criar esboços bíblicos próprios, estruturados em tema central, pontos e subpontos, vinculados a livros e versículos. A navegação pelos 66 livros da Bíblia acontece em uma estante 3D interativa.

## Stack

**Frontend:** Next.js (App Router) · TypeScript estrito · Tailwind CSS · TanStack Query · Zod

**Backend:** NestJS · Prisma · PostgreSQL · autenticação JWT com refresh token
